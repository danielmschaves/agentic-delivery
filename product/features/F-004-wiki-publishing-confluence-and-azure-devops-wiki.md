# Wiki publishing: Confluence and Azure DevOps Wiki

## Problem

Stakeholders read Confluence or the ADO Wiki, not git repos.

## Proposal

Add a `WikiPort` with Confluence and ADO Wiki adapters. `ad wiki publish` pushes the PRD, features
and generated outputs to a configured space, and is idempotent by page id.
