# Communication ingestion: mail, calendar, meeting transcripts

## Problem

Decisions are made in meetings and email threads, and are lost.

## Proposal

Ingest meeting transcripts (Zoom, Teams), calendar events and selected mail threads (Gmail,
Outlook) into `kb/` via the same `/ingest` flow, with explicit user selection. There is no bulk
mailbox crawl.
